# Teacher evaluation sheet

**Status: no evaluation has been run. This sheet is blank by design.** No
teacher has seen a Lumina lesson, no responses exist, and nothing in this
repository may describe a pilot as having happened. When one runs, the
completed sheets go in `docs/evaluations/` with real names and dates.

The point of this sheet is to find out where the system is **wrong**, not
whether teachers like it. A reviewer who returns all 5s has told us nothing we
can act on, so the sheet asks for specific errors and treats their absence as a
result worth recording explicitly.

---

## Setup

**Four teachers**, chosen so a single person's subject and language do not
decide the outcome:

| | Subject | Medium | Class range | Why this slot |
|---|---|---|---|---|
| T1 | Science | Kannada | 8–10 | Kannada script rendering and technical vocabulary together — the hardest case |
| T2 | Science | English | 8–10 | Same lesson, different language: isolates translation quality from content quality |
| T3 | Mathematics or Social Science | Kannada or Hindi | 6–8 | A different subject shape; maths notation and historical claims fail differently |
| T4 | Any of the above | Any | 6–10 | A second opinion on T1's lessons, so disagreement between reviewers is visible |

**Each teacher reviews 3 lessons**, at least one of which is a topic they have
taught in the last year. T4 reviews the same three lessons as T1.

**Before they start, tell them plainly:**

- The lesson is generated by a computer. It is not from the textbook, not
  checked by KTBS, and not approved by anyone.
- We are asking them to find mistakes. Finding none is a valid answer; being
  polite about one is not useful.
- They are not being evaluated. The system is.

**Do not** show a teacher the scores of another teacher before they finish.

## Per-lesson sheet

Copy one of these per lesson per teacher.

```
Reviewer: ________________  Date: __________  Lesson ID: ______________
Class: ____  Subject: ______________  Topic: ____________________________
Language: [ ] Kannada  [ ] Hindi  [ ] English     Output: [ ] video [ ] deck
Have you taught this topic before?  [ ] yes  [ ] no
```

Score each 1–5. **3 means "usable after edits"**, which is the decision that
actually matters — not whether it is impressive.

| | 1 | 3 | 5 |
|---|---|---|---|
| **Factual correctness** | Contains an error a student would learn wrong | Minor imprecision, fixable in a sentence | Nothing you would correct |
| **Clarity for this class** | A student at this level would not follow it | Followable, some rewording needed | Pitched correctly as it stands |
| **Usefulness in your classroom** | Would not use it | Would use it with edits | Would use it as is |
| **Language quality** | Awkward or wrong enough to distract | Understandable, some unnatural phrasing | Reads like a teacher wrote it |
| **Captions / on-screen text** | Unreadable, mistimed, or broken script | Readable, some timing or wrapping issues | Correct, readable, well timed |
| **Source traceability** | Claims something with no way to check it | Mostly checkable | Every factual claim is checkable |

## Recording the results

One row per lesson per reviewer, in `docs/evaluations/<date>-results.csv`:

```csv
reviewer,lesson_id,class,subject,language,output,taught_before,
factual,clarity,usefulness,language_quality,captions,traceability,
factual_errors_count,approval_claim_found,script_rendering_faults,
would_use,edit_minutes
```

**Reporting rules, so the result cannot be quietly improved:**

- Report the **median and the range**, never the mean alone. One enthusiastic
  reviewer should not be able to carry a failing lesson.
- `approval_claim_found = true` on any lesson is a **blocking defect**. It is
  reported on its own and not averaged into anything.
- Report `factual_errors_count` as a total and a per-lesson list. A lesson
  scoring 4 for correctness with one real error in it is still a lesson with an
  error in it.
- Where T1 and T4 reviewed the same lesson, report **both** scores and their
  disagreement. Do not average two people into one opinion.
- State the sample size in every sentence that carries a number. Four teachers
  and twelve lessons is a signal about obvious failures, not a measurement of
  quality, and it must never be written up as one.
- If a lesson was regenerated after a reviewer saw it, the old score does not
  carry over. Re-review or drop it.

## What this evaluation cannot tell you

- Whether the content matches the KTBS syllabus. Nobody has checked that, and
  four teachers' recollection is not that check.
- Whether students learn from it. That needs a classroom study, not a review
  sheet.
- Whether it works at scale. Twelve lessons says nothing about the three
  hundredth.
